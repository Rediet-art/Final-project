# Final-project
Nao5 AI Learn Web Application
Kids Learning App – Simplifying Complex Topics for Children

This project is a child-friendly web application designed to explain complex topics in simple, easy-to-understand language for young children. 
It includes features such as AI-generated explanations, voice input, parental consent, and a clean, colourful interface suitable for ages 5–12.

## Features

- User signup and login
- Parental consent check before accessing the app
- Dashboard for asking learning questions
- Age-level selection for simpler explanations
- Voice input page using speech recognition
- Text-to-speech replay for voice answers
- Learning history saved per user
- Profile and navigation pages

## Testing

This project uses Jest for automated testing.

The tests cover:

- Signup validation
- Login validation
- Dashboard question handling and history saving
- Voice input request handling, text cleaning, and history saving
